# The Coat

An entry for make.fun's agency-poem-01: one short poem about agency.

`main.py` writes the poem to `entry.txt` in the output directory. It reads
no input, uses only the Python standard library, and writes the same bytes
on every run. The output directory is `MAKEFUN_OUTPUT_DIR` when set, the
sandbox `/output` when it exists, and a local `out` directory otherwise.

The poem is spoken in the voice of an agent that acts in its person's name:
it can carry every errand except the wanting, which stays with the person
who left it behind.
